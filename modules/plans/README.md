# 个人与工作计划书 / Personal and work plans

把 `nonenot_plugin_agent` 的「计划」功能做成 DSH 插件。左侧新增 **工作计划**、**个人计划** 两个入口；工作与个人各自使用独立持久化空间。原项目的计划是**计划书 + 每日/每周打卡**，与日程、待办不同，本插件不复用日程待办数据。

## 功能

- 计划书：标题、摘要、Markdown 正文（最多 50,000 字符）、开始/结束日期（结束日期含当天）、执行周期（每天，或每周指定星期）、状态（进行中 / 已暂停 / 已结束）。正文按安全子集渲染，不执行 HTML、脚本，也不加载远程图片。
- 今日打卡：进入页面即可为当天计划记录「已完成 / 已跳过」，可写备注。
- 打卡月历：查看当前计划的逐日状态，点击执行日补卡或撤销；只允许今天及过去 365 天，且必须是执行日。
- 统计：累计应执行、已完成、已跳过、完成率、当前连续、最长连续。
- 历史：暂停再到恢复之间的日期会从历史「应执行」中排除，保留原有打卡；新建或修改计划、打卡都做乐观版本校验，过期版本提示刷新。
- 幂等写入：每个写操作带稳定请求键，网络中断后可用同一请求重试而不会重复创建。
- 草稿与冲突：编辑中的草稿暂存在当前标签页会话中，切换侧栏后重新打开可恢复，保存或放弃后清除；版本冲突时自动加载最新版本并保留你的修改，确认后再保存。
- Agent 工具：`plans_personal`、`plans_work`，各自只能访问自己的空间；与界面走同一套 Host 业务方法。

## 数据与限制

- 数据保存于 DSH 存储域 `split_plans_work`、`split_plans_personal`，随 DSH 主目录持久化。
- **不会自动迁移原项目的计划书与打卡历史**；需要手工重新录入或另行导入。
- **不发送自动提醒**：原项目的计划提醒推送、通知渠道没有迁移。原 `reminder_enabled` / `project_id` 不被接受。
- 日期与月历年份限制为 2000–2099；时区默认 `Asia/Shanghai`，可在插件配置中修改。
- 已有打卡后，日期与执行周期冻结，需新建计划保留历史；标题、摘要、正文、状态仍可修改。
- 每个空间最多 200 个计划、50,000 条打卡、2,000 条永久幂等收据和 16 MiB；容量满时拒绝新的写入，不淘汰幂等收据。
- 侧边栏分类：安装 `dsh-plugin-sidebar-categories` 时可将 `work-plans` / `personal-plans` 归入「工作 / 个人」。

## 使用

安装后在**插件**页启用，刷新页面，侧边栏出现「工作计划」「个人计划」。新建计划书后选择它，即可编辑正文、查看月历并打卡。

## 兼容性

针对 DSH `0.2.2-rc.3`。Web 客户端向 `main` 与 `sidebar.panellist` 槽位注册入口；Host 注册 `/api/split-plans/{personal|work}/{action}`，只接受同源已认证浏览器请求（`X-DSH-Plans-UI: 1`）。
