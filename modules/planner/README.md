# 工作与个人日程待办 / Work and personal planner

为 DeepSeek Harness 增加四个侧边栏入口：**工作日程**、**工作待办**、**个人日程**、**个人待办**。工作与个人使用彼此独立的持久化空间，互不可见。

## 功能

- 日程：标题、描述、标签、开始/结束、全天（结束日期不包含）、IANA 时区、重复（每天 / 每周指定星期 / 每月指定日期，可设置截止日期或总次数）、取消单次发生、提醒提前分钟。
- 待办：标题、描述、标签、项目、优先级、截止时间、父任务（父子必须同空间且不能成环）、完成 / 重新打开、提醒提前分钟。
- 搜索与状态筛选；日历发生列表（有界范围，最长 366 天，按本地墙上时间展开重复，跳过不存在的月底日期与夏令时缺口）。
- 提醒概览：列出未来 7 天内到点的提醒。**仅页面展示，不做后台推送。**
- 乐观并发：每条记录带递增版本号，过期版本写入返回冲突提示，先刷新再重试。
- Agent 工具：`planner_work`、`planner_personal`，与界面调用同一套 Host 操作；只读写各自空间。

## 数据与限制

- 数据保存于 DSH 存储域 `split_planner_work`、`split_planner_personal`，随 DSH 主目录持久化。
- **不会自动迁移原项目（nonenot_plugin_agent）的日程/待办数据**，需要手工重新录入或另行导入。
- 定时时间必须带 `Z` 或 `±HH:MM` 偏移；界面不会按固定 `+08:00` 猜测偏移。全日程使用 `YYYY-MM-DD`。
- 提醒没有后台投递、没有重复提醒队列；原项目的推送/稍后提醒语义未迁移。
- 侧边栏分类：安装 `dsh-plugin-sidebar-categories` 时，本插件为 `personal-*` 入口补充了默认「个人」分类规则；若该插件升级覆盖，应在分类设置里手动把两个个人入口移到「个人」。

## 使用

安装后在**插件**页启用，刷新页面，侧边栏出现四个入口。若侧栏使用分类插件，请在「工作 / 个人」分组中查看；未安装分类插件时四个入口依次排列。

## 兼容性

针对 DSH `0.2.2-rc.3`。Web 客户端注册 `main` 与 `sidebar.panellist` 槽位；Host 注册 `/api/split-planner/{personal|work}/{action}` 路由，只接受同源已认证浏览器请求（`X-DSH-Planner-UI: 1`）。
