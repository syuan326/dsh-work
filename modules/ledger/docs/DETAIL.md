# 个人账本 · DSH 插件

这是从秘书账本业务迁移的 DSH 原生插件，左侧入口为「账本」。页面和 LLM 工具共用 Host 端服务及持久化数据，不再将账目保存在浏览器 localStorage。

## 功能

- 收入／支出明细，日期与分类筛选、搜索、分页，页面新增、编辑及确认删除。
- 月／季／年收支统计、分类汇总、累计结余、分类预算。
- 储蓄目标、分期／借贷、报销和还款／回款结算；分期最后一期处理尾差，同步生成的账目与结算一起更新。
- 分类维护；JSON 先预览数量、逐月合计及冲突，再确认导入。重复相同记录跳过；冲突整批不写入。
- 金额使用整数分，写入经过版本检查和幂等去重；持久化成功后才报告成功。损坏数据拒绝加载，不用空账本覆盖。

## LLM 工具

- `ledger_options`：分类与默认日期／时区。
- `ledger_query`：明细查询；支持分页和精确账目 ID。
- `ledger_summary`：日期范围汇总、分类及预算执行。
- `ledger_planning`：储蓄、借贷、报销及结算进度。
- `create_ledger_entry`：仅用户明确要求时新增账目。金额以人民币元的字符串提供，例如 `25.50`。缺少金额、方向或分类时先询问；同一笔请求失败重试必须复用 `idempotency_key`。

模型没有修改、删除、调整预算／规划或批量导入工具。页面管理操作需要已认证的 DSH 浏览器身份。

## 数据与迁移

数据通过当前 profile 的 DSH storageDomain 保存，域名 `personal_ledger`，作为一次原子快照提交，不直接操作原 NoneBot 数据库。停止 DSH 后的 profile 数据备份可保留此域；也可从页面导出独立 JSON。

从原秘书页面导出 `pardo-secretary-ledger` **v2** JSON，再在这里预览并确认导入。此版本不自动读取原数据库、不自动同步；旧 `paddys-ledger` v1 必须先由原秘书转换为 v2。前一版 DSH 浏览器本地记录只有显式迁移后才进入 Host，不能自动当作原秘书备份。

默认时区为 Asia/Shanghai。规划中的提醒字段作为数据保留，预算状态可在页面查看，**不创建或投递后台提醒通知**。

## 安装和验证

通过 DSH「插件 → 添加插件」选择本目录。更新已经安装的插件后，按插件管理器返回的说明重启 DSH，再刷新原页面。不要启动另一个 Web 服务器。

开发检查：`npm run check`、`npm test`。完整的浏览器交互、深浅主题及安装后工具可见性需要在已连接的 DSH 页面验证；静态检查不等于页面验收。
